💰 Personal Expense Tracker

A simple and user-friendly Personal Expense Tracker built using C++. The application helps users manage their daily income and expenses, track transactions, calculate their balance, and view monthly summaries.

📌 Problem Statement

Managing daily expenses manually can make it difficult to keep track of spending and savings. This project provides a simple console-based solution for recording and managing financial transactions.

✨ Features

- Add income
- Add expenses
- View all transactions
- Search transactions
- Update transactions
- Delete transactions
- Calculate total income
- Calculate total expenses
- Check remaining balance
- View monthly summary
- Store transactions using file handling
- Maintain data after restarting the application

🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL Vector
- File Handling
- Command Line Interface (CLI)

▶️ How to Run

Step 1: Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the Project Folder

cd Personal-Expense-Tracker

Step 3: Compile the Program

g++ main.cpp -o expense_tracker

Step 4: Run the Program

Windows:

.\expense_tracker

Linux/Mac:

./expense_tracker
